# reels-cola

Buzón de los reels de @naisa.hosteleria que van a publicarse. Cada semana se suben aquí los vídeos y `cola.json`
(fecha y hora de Madrid, texto y primer comentario). El servidor que publica los recoge solo cada hora con
`recoger.py`; `instalar.sh` lo pone en marcha una vez. Aquí no hay claves ni datos de clientes.
